# Use Irreplaceable in ChatGPT (no Claude, no skills needed)
© 2026 BringLife Digital

## Option 1 · Paste the prompt (free ChatGPT works)
1. Open chatgpt.com (or Gemini, Copilot, Claude: any chat AI).
2. Copy everything in `prompt.md` and paste it as your first message.
3. Answer its questions. To share your résumé, attach the file or paste the text.

## Option 2 · Save it as your own GPT (ChatGPT Plus)
So you can come back any time without pasting:
1. chatgpt.com → Explore GPTs → **+ Create** → **Configure**.
2. **Name:** Irreplaceable · **Description:** Will AI replace me? Check, score and a 30-day plan.
3. **Instructions:** paste `prompt.md`, but delete the last line "Start with STEP 1 now."
4. **Conversation starters:** "Will AI replace me?" · "Re-take my Irreplaceable check" · "Improve this prompt: …"
5. **Capabilities:** keep Code Interpreter on (it reads uploaded résumés). Web search optional.
6. **Create** → choose *Only me* or *Anyone with the link*.
