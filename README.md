# Irreplaceable 🧠
**A free Claude skill for anyone worried AI will replace them.**
By [BringLife Digital](https://bringlifedigital.com/skills/) · MIT licence

## What happens
1. **Our story:** how I made myself irreplaceable from AI, in 5 short chapters.
2. **"Will AI replace me?" self-check:** 10 quick questions about tasks AI is already absorbing, plus what's still yours.
3. **Want to improve?** Optional assessment: upload your résumé and take a 12-question quiz, scored out of 100. Skip it if you like.
4. **Your plan:** honest résumé upgrades, a 30-day plan on your real work, and the best open-source agent skills on GitHub for your gaps.
5. **Bonus skill:** Prompt Coach, which makes you better at using AI every time you use it.

## Install
- **Claude app / claude.ai:** download the zip from [bringlifedigital.com/skills](https://bringlifedigital.com/skills/#irreplaceable) → Settings → Capabilities → Skills → Upload skill.
- **Claude Code:** `git clone https://github.com/BringLife-digital/irreplaceable ~/.claude/skills/irreplaceable`

Then ask Claude: **"Will AI replace me?"**
